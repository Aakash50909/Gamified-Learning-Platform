# LearnQuest

Where Learning Meets Play.

Welcome to LearnQuest, a platform designed to make skill mastery as addictive as your favorite games. We believe that the biggest hurdle to learning isn't the difficulty of the subject—it’s the lack of consistent motivation. LearnQuest solves this by wrapping educational content in a gamified, competitive ecosystem.

Whether you're practicing C++ algorithms, solving math puzzles, or competing in a trivia league, LearnQuest tracks your progress, rewards your consistency with XP and badges, and connects you with a community of fellow "questers."
## Features

    Gamified Learning: Earn XP, level up, and unlock achievements as you complete modules.

    Real-time Competitions: Join tournaments with live leaderboards and automated scoring.

    Social Hub: Discuss challenges, message friends, and stay updated via your activity feed.

    Virtual Rewards: Spend earned coins on custom avatars and profile themes.

    Admin Dashboard: Comprehensive tools for organizers to manage events and track analytics.

## The Tech Stack

    Frontend: React / Next.js, Tailwind CSS, Shadcn UI

    Backend: Node.js (Express), JWT Auth, Render.com

    Database: MongoDB Atlas

    Ops: GitHub Actions for CI/CD, Vercel for hosting
